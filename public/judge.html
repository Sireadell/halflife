Halflife certifies AI agents, then takes the certificate away if they get worse.

Most agent tests happen once. Halflife keeps the history alive: test the agent, publish the certificate to Arc, check it again later, and revoke the certificate when the agent no longer holds up.

Complete app flow

From agent owner to public proof.

Halflife is built for agents whose owners want a checkable trust record, not for secretly attacking someone else's agent.

1

Owner submits an agent

The owner provides the agent endpoint, the agent wallet, and a sample request body so the test can run against the right target.

2

Halflife runs the test

The agent is checked for brittle behavior, bad confidence, and responses that look successful when they should not.

3

Arc stores the certificate

When the agent passes, Halflife writes the certificate fingerprint to Arc mainnet so the record is not just our database.

4

Later checks can revoke it

If the agent gets worse, Halflife writes the revoke record to Arc and the public history changes from certified to revoked.

Current limit: today this is for agents whose owners can prove control. Vetting a stranger's agent without cooperation is a harder problem and not claimed here.
